# SpeakSpace

A simple platform designed to help people practice and improve their English speaking skills through topics, timers, voice recordings, and optional Gemini feedback.

## Run locally

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env` and add your Gemini API key for AI feedback.
3. Start the app with `npm start`.
4. Open <http://localhost:3000>.

Without a Gemini key, recording, playback, and local history still work. Only optional AI feedback is unavailable.

Run `npm test` to check the JavaScript files for syntax errors.
